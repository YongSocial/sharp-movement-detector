What this does

This agent connects directly to TxLINE's live odds stream and watches every price update in real time. When a bookmaker's odds move sharply during a live match — more than a set threshold, in either direction — it's logged as a signal.

Why it matters

Sharp, sudden odds moves during play often reflect new information hitting the market faster than the average viewer can react: an injury, a tactical shift, momentum swinging. Tracking these moves systematically turns market behavior into a readable signal.

Self-grading loop

Every signal is checked against the final match result once it's available. If odds shortened toward the outcome that happened, or drifted away from the outcome that didn't, it's marked correct. This produces a running accuracy score — the system checks its own predictive value automatically, with no manual grading.

Architecture

Node.js agent streams odds via SSE, filters for in-play movement only (pre-match churn is excluded as noise), and persists every signal to a Postgres database (Supabase). A lightweight API serves this dashboard, which is fully static and hosted separately on GitHub Pages.
