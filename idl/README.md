Download the real IDL before running `npm run activate`:

- Mainnet: https://txline.txodds.com/documentation/programs/mainnet
- Devnet:  https://txline.txodds.com/documentation/programs/devnet

Save the JSON as `idl/txoracle.json` in this folder. It's not vendored here
since it's fetched live from TxODDS docs and may change between hackathon
phases.
